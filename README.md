# Light-Speed Float

An interactive speedometer that helps A-level students work out 8-bit floating point binary.

- **8-bit mantissa + 4-bit exponent**, both two's complement, with the binary point after the first mantissa bit.
- **Explore:** flip the bits and the needle moves, from a snail's pace up to the speed of light. Three worked steps show how the value is found: work out the exponent, move the binary point, add up the place values.
- **Test me:** students answer each of the three steps in turn. Each correct step unlocks the next, with hints for common mistakes and a "Show me" option after two wrong tries.

- **Normalising page** (`normalise.html`): turn a denary number into a normalised mantissa and exponent, step by step. Students remove supports one at a time: hints, place-value helpers, the point mover, and finally the step boxes themselves.

Open `index.html` in a browser to use it. No build step needed.
